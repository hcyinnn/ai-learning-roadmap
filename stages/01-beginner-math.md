## 📖 学习内容

### 1. 线性代数 (2-3周)

线性代数是AI和机器学习的基石。几乎所有的机器学习算法都依赖于线性代数的运算，从数据表示到模型训练，线性代数无处不在。

#### 1.1 向量与矩阵

**向量（Vector）**

向量是线性代数中最基本的概念之一。在AI中，我们通常用向量来表示数据点、特征和模型参数。

- **定义**：向量是一个有序的数字列表，可以表示空间中的一个点或方向
- **表示方法**：
  - 列向量：`v = [v₁, v₂, ..., vₙ]ᵀ`
  - 行向量：`v = [v₁, v₂, ..., vₙ]`
- **基本运算**：
  - 向量加法：`u + v = [u₁+v₁, u₂+v₂, ..., uₙ+vₙ]`
  - 标量乘法：`c * v = [c*v₁, c*v₂, ..., c*vₙ]`
  - 向量点积：`u · v = u₁v₁ + u₂v₂ + ... + uₙvₙ`
  - 向量范数：`||v|| = √(v₁² + v₂² + ... + vₙ²)`

- **在AI中的应用**：
  - 数据表示：每个数据样本可以用一个特征向量表示
  - 词向量：Word2Vec等模型将词语映射为向量
  - 相似度计算：通过向量点积或余弦相似度衡量数据相似性

**矩阵（Matrix）**

矩阵是二维的数字数组，是线性代数的核心工具。在AI中，矩阵用于表示数据集、权重和变换。

- **定义**：m×n矩阵是一个m行n列的矩形数组
- **特殊矩阵**：
  - 零矩阵：所有元素为0
  - 单位矩阵：对角线为1，其余为0
  - 对角矩阵：只有对角线有非零元素
  - 对称矩阵：A = Aᵀ
  - 正交矩阵：AᵀA = AAᵀ = I

#### 1.2 矩阵运算

矩阵运算是线性代数的核心，掌握这些运算是理解AI算法的基础。

**基本运算**：
- **矩阵加法**：对应元素相加，要求维度相同
- **标量乘法**：每个元素乘以标量
- **矩阵乘法**：
  - 条件：A(m×n) × B(n×p) = C(m×p)
  - 计算：C_ij = Σ(k=1 to n) A_ik × B_kj
  - 性质：不满足交换律（AB ≠ BA），但满足结合律

**重要性质**：
- 转置：(AB)ᵀ = BᵀAᵀ
- 逆矩阵：AA⁻¹ = A⁻¹A = I
- 行列式：det(AB) = det(A) × det(B)

**在AI中的应用**：
- 线性变换：y = Wx + b（神经网络的基本操作）
- 批量数据处理：将多个样本表示为矩阵进行并行计算
- 特征变换：PCA等降维方法的核心

#### 1.3 特征值与特征向量

特征值和特征向量是理解数据结构和降维的关键概念。

- **定义**：对于矩阵A，如果存在非零向量v和标量λ，使得 Av = λv，则λ是特征值，v是对应的特征向量
- **计算方法**：
  - 特征方程：det(A - λI) = 0
  - 求解特征多项式得到特征值
  - 代入求解特征向量

- **重要性质**：
  - 特征值之和等于矩阵的迹（trace）
  - 特征值之积等于矩阵的行列式
  - 对称矩阵的特征值都是实数

- **在AI中的应用**：
  - PCA降维：选择最大特征值对应的特征向量
  - 谱聚类：基于图拉普拉斯矩阵的特征分解
  - 稳定性分析：判断系统的稳定性

#### 1.4 线性变换

线性变换是向量空间之间的映射，保持向量加法和标量乘法运算。

- **定义**：T(v) = Av，其中A是变换矩阵
- **常见变换**：
  - 旋转：R(θ) = [[cosθ, -sinθ], [sinθ, cosθ]]
  - 缩放：S = [[sx, 0], [0, sy]]
  - 投影：将向量投影到某个子空间

- **在AI中的应用**：
  - 神经网络层：每层都是一个线性变换（加激活函数）
  - 数据增强：通过变换生成新的训练样本
  - 坐标变换：在不同坐标系之间转换

#### 1.5 线性代数在AI中的综合应用

1. **数据表示与处理**
   - 数据集表示为矩阵：每行一个样本，每列一个特征
   - 特征标准化：(x - μ) / σ
   - 缺失值处理：矩阵补全技术

2. **降维技术**
   - PCA（主成分分析）：找到数据的主要方向
   - SVD（奇异值分解）：A = UΣVᵀ
   - 应用：数据压缩、噪声去除、可视化

3. **神经网络基础**
   - 前向传播：y = σ(Wx + b)
   - 权重初始化：Xavier、He初始化
   - 批量归一化：标准化中间层输出

### 2. 概率统计 (2-3周)

概率统计是处理不确定性和从数据中学习的数学框架。在AI中，概率论帮助我们建模不确定性，统计学帮助我们从数据中做出推断。

#### 2.1 概率基础

**概率的定义与性质**

- **频率学派**：概率是事件发生的长期频率
- **贝叶斯学派**：概率是对事件发生的信念程度
- **基本性质**：
  - 0 ≤ P(A) ≤ 1
  - P(Ω) = 1（必然事件概率为1）
  - P(A∪B) = P(A) + P(B) - P(A∩B)

**条件概率**

- **定义**：P(A|B) = P(A∩B) / P(B)
- **乘法公式**：P(A∩B) = P(A|B) × P(B)
- **全概率公式**：P(A) = Σ P(A|Bi) × P(Bi)

**贝叶斯定理**

贝叶斯定理是概率论中最重要的定理之一，它描述了如何根据新证据更新我们的信念。

- **公式**：P(A|B) = P(B|A) × P(A) / P(B)
- **组成部分**：
  - P(A|B)：后验概率（看到证据后的信念）
  - P(B|A)：似然度（在A下看到B的概率）
  - P(A)：先验概率（初始信念）
  - P(B)：证据（归一化常数）

- **在AI中的应用**：
  - 朴素贝叶斯分类器：文本分类、垃圾邮件过滤
  - 贝叶斯网络：建模变量之间的依赖关系
  - 贝叶斯优化：超参数调优
  - 贝叶斯深度学习：模型不确定性估计

#### 2.2 常见概率分布

**离散分布**

1. **伯努利分布（Bernoulli）**
   - 描述：单次试验，成功概率p
   - PMF：P(X=k) = p^k × (1-p)^(1-k)，k∈{0,1}
   - 期望：E[X] = p
   - 方差：Var(X) = p(1-p)
   - 应用：二分类问题、逻辑回归输出

2. **二项分布（Binomial）**
   - 描述：n次独立试验中成功的次数
   - PMF：P(X=k) = C(n,k) × p^k × (1-p)^(n-k)
   - 期望：E[X] = np
   - 方差：Var(X) = np(1-p)
   - 应用：A/B测试、多次试验的结果建模

3. **泊松分布（Poisson）**
   - 描述：单位时间内事件发生的次数
   - PMF：P(X=k) = (λ^k × e^(-λ)) / k!
   - 期望和方差：E[X] = Var(X) = λ
   - 应用：稀有事件建模、计数数据

**连续分布**

1. **均匀分布（Uniform）**
   - 描述：在[a,b]区间内等可能取值
   - PDF：f(x) = 1/(b-a)，a≤x≤b
   - 期望：E[X] = (a+b)/2
   - 方差：Var(X) = (b-a)²/12
   - 应用：随机初始化、蒙特卡洛采样

2. **正态分布（Normal/Gaussian）**
   - 描述：最重要的连续分布，钟形曲线
   - PDF：f(x) = (1/√(2πσ²)) × exp(-(x-μ)²/(2σ²))
   - 记号：X ~ N(μ, σ²)
   - 性质：68-95-99.7法则
   - 应用：噪声建模、中心极限定理、高斯过程

3. **指数分布（Exponential）**
   - 描述：事件之间的时间间隔
   - PDF：f(x) = λe^(-λx)，x≥0
   - 无记忆性：P(X>s+t|X>s) = P(X>t)
   - 应用：生存分析、排队论

#### 2.3 统计量与估计

**描述统计**

- **集中趋势**：
  - 均值：x̄ = (1/n)Σxᵢ
  - 中位数：排序后中间的值
  - 众数：出现频率最高的值

- **离散程度**：
  - 方差：s² = (1/(n-1))Σ(xᵢ - x̄)²
  - 标准差：s = √s²
  - 极差：max - min
  - 四分位距：Q3 - Q1

- **分布形状**：
  - 偏度：衡量分布的对称性
  - 峰度：衡量分布的尖锐程度

**点估计**

- **最大似然估计（MLE）**：
  - 思想：选择使观测数据出现概率最大的参数
  - 步骤：写出似然函数 → 取对数 → 求导 → 解方程
  - 例子：正态分布的MLE就是样本均值和方差

- **矩估计**：
  - 思想：用样本矩估计总体矩
  - 优点：计算简单
  - 缺点：可能不是最有效的估计

**区间估计**

- **置信区间**：参数的可能范围
- **计算方法**：估计值 ± 临界值 × 标准误
- **解释**：在重复抽样下，95%的置信区间包含真实参数

#### 2.4 假设检验

假设检验是统计推断的重要工具，用于判断数据是否支持某个假设。

**基本概念**
- **原假设（H₀）**：默认假设，通常表示没有效应
- **备择假设（H₁）**：研究者想要证明的假设
- **P值**：在原假设下，观测到当前或更极端结果的概率
- **显著性水平（α）**：拒绝原假设的阈值，通常0.05

**检验步骤**
1. 建立假设：H₀和H₁
2. 选择检验统计量
3. 计算P值
4. 做出决策：P < α则拒绝H₀

**常见检验**
- **t检验**：比较均值
- **卡方检验**：比较分类变量
- **ANOVA**：比较多组均值

**在AI中的应用**：
- A/B测试：比较两种算法的效果
- 特征选择：检验特征与目标的相关性
- 模型评估：判断模型改进是否显著

#### 2.5 概率统计在AI中的综合应用

1. **概率模型**
   - 贝叶斯网络：建模变量间的依赖关系
   - 马尔可夫模型：序列数据建模
   - 隐马尔可夫模型（HMM）：语音识别、生物序列分析

2. **不确定性估计**
   - 模型置信度：输出概率而非确定类别
   - 贝叶斯神经学习：权重量化不确定性
   - 集成方法：通过多个模型估计不确定性

3. **生成模型**
   - 高斯混合模型（GMM）：聚类和密度估计
   - 变分自编码器（VAE）：学习数据的潜在分布
   - 生成对抗网络（GAN）：生成逼真的数据

### 3. 微积分 (2-3周)

微积分是研究变化的数学分支。在AI中，微积分主要用于优化问题，特别是通过梯度下降来训练模型。

#### 3.1 极限与连续

**极限的概念**

- **定义**：当x趋近于a时，f(x)趋近于L，记作 lim(x→a) f(x) = L
- **性质**：
  - 唯一性：极限如果存在则唯一
  - 局部有界性：极限存在则局部有界
  - 保号性：极限保持不等号方向

**连续性**

- **定义**：函数在某点连续，当且仅当极限值等于函数值
- **间断点类型**：
  - 可去间断点：极限存在但不等于函数值
  - 跳跃间断点：左右极限存在但不相等
  - 无穷间断点：极限为无穷

**在AI中的应用**：
- 损失函数设计：确保损失函数连续可导
- 激活函数：ReLU在0点的连续性问题
- 优化算法：连续性保证梯度下降的有效性

#### 3.2 导数与偏导数

**导数**

- **定义**：f'(x) = lim(h→0) [f(x+h) - f(x)] / h
- **几何意义**：切线的斜率
- **物理意义**：瞬时变化率

**基本导数公式**：
- (xⁿ)' = nxⁿ⁻¹
- (eˣ)' = eˣ
- (ln x)' = 1/x
- (sin x)' = cos x
- (cos x)' = -sin x

**求导法则**：
- 加法法则：(f+g)' = f' + g'
- 乘法法则：(fg)' = f'g + fg'
- 除法法则：(f/g)' = (f'g - fg') / g²
- 链式法则：(f(g(x)))' = f'(g(x)) × g'(x)

**偏导数**

- **定义**：多元函数对某一变量的导数，其他变量视为常数
- **表示**：∂f/∂xᵢ
- **计算**：将其他变量看作常数，对目标变量求导

**在AI中的应用**：
- 梯度计算：损失函数对参数的偏导数
- 反向传播：链式法则在神经网络中的应用
- 敏感性分析：了解输入变化对输出的影响

#### 3.3 梯度

**梯度的定义**

- **定义**：多元函数的所有偏导数组成的向量
- **表示**：∇f = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]
- **几何意义**：函数增长最快的方向
- **性质**：梯度方向是函数值增加最快的方向，负梯度方向是减少最快的方向

**梯度的计算**

对于函数f(x₁, x₂, ..., xₙ)：
- 计算每个偏导数 ∂f/∂xᵢ
- 组合成向量 [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]

**梯度的性质**：
- 梯度垂直于等值线/等值面
- 梯度的大小表示变化率
- 梯度为0的点可能是极值点

**在AI中的应用**：
- 梯度下降：x_new = x_old - η∇f(x_old)
- 反向传播：通过链式法则计算梯度
- 优化算法：SGD、Adam等都基于梯度

#### 3.4 积分基础

**不定积分**

- **定义**：求导的逆运算
- **表示**：∫f(x)dx = F(x) + C
- **基本公式**：
  - ∫xⁿdx = xⁿ⁺¹/(n+1) + C (n≠-1)
  - ∫eˣdx = eˣ + C
  - ∫1/x dx = ln|x| + C

**定积分**

- **定义**：函数在区间上的累积量
- **几何意义**：曲线下面积
- **计算**：∫[a,b] f(x)dx = F(b) - F(a)

**数值积分**
- 矩形法：用矩形近似面积
- 梯形法：用梯形近似面积
- 辛普森法：用抛物线近似面积

**在AI中的应用**：
- 概率计算：连续随机变量的概率是PDF的积分
- 期望计算：E[X] = ∫xf(x)dx
- 归一化：确保概率密度积分为1

#### 3.5 微积分在AI中的综合应用

1. **梯度下降优化**
   - 基本形式：θ = θ - η∇L(θ)
   - 随机梯度下降（SGD）：用单个样本估计梯度
   - 小批量梯度下降：用小批量样本估计梯度
   - 动量法：累积历史梯度信息

2. **反向传播算法**
   - 链式法则的应用
   - 计算图：前向传播和反向传播
   - 梯度消失和爆炸问题
   - 解决方案：ReLU、残差连接、梯度裁剪

3. **损失函数设计**
   - 均方误差：MSE = (1/n)Σ(yᵢ - ŷᵢ)²
   - 交叉熵：H(y, ŷ) = -Σyᵢlog(ŷᵢ)
   - 梯度计算：对损失函数求导

4. **优化算法**
   - SGD + 动量
   - RMSprop
   - Adam：结合动量和自适应学习率
   - 学习率调度：余弦退火、预热

### 4. 优化理论 (1-2周)

优化理论是AI的核心，因为机器学习本质上是一个优化问题：找到使损失函数最小的模型参数。

#### 4.1 凸优化基础

**凸集与凸函数**

- **凸集**：集合中任意两点的连线仍在集合内
  - 例子：超平面、半空间、球体
  - 性质：凸集的交集仍是凸集

- **凸函数**：函数图像上任意两点连线在函数图像上方
  - 判定：f(θx + (1-θ)y) ≤ θf(x) + (1-θ)f(y)
  - 一阶条件：f(y) ≥ f(x) + ∇f(x)ᵀ(y-x)
  - 二阶条件：Hessian矩阵半正定

**凸优化问题**

- **标准形式**：
  ```
  minimize    f(x)
  subject to  gᵢ(x) ≤ 0, i=1,...,m
              hⱼ(x) = 0, j=1,...,p
  ```
- **重要性质**：
  - 局部最优就是全局最优
  - 可以高效求解
  - KKT条件是最优性的充要条件

**在AI中的应用**：
- 线性回归：最小二乘是凸优化问题
- 逻辑回归：交叉熵损失是凸函数
- SVM：对偶问题是凸二次规划

#### 4.2 梯度下降法

**基本梯度下降**

- **算法**：
  ```
  初始化 θ
  重复：
    计算梯度 g = ∇L(θ)
    更新 θ = θ - ηg
  直到收敛
  ```
- **学习率η的选择**：
  - 太大：震荡，可能发散
  - 太小：收敛慢
  - 通常需要实验调优

**随机梯度下降（SGD）**

- **动机**：大数据集上计算全部梯度太慢
- **算法**：
  ```
  对每个样本 (xᵢ, yᵢ)：
    计算梯度 gᵢ = ∇L(θ; xᵢ, yᵢ)
    更新 θ = θ - ηgᵢ
  ```
- **优点**：计算快，能跳出局部最优
- **缺点**：梯度估计有噪声

**小批量梯度下降**

- **折中方案**：每次用b个样本估计梯度
- **典型批量大小**：32, 64, 128, 256
- **优点**：
  - 利用矩阵运算的并行性
  - 梯度估计更稳定
  - 内存效率高

**动量法**

- **动机**：加速收敛，减少震荡
- **算法**：
  ```
  v = βv + η∇L(θ)
  θ = θ - v
  ```
- **解释**：像球滚下山坡，积累动量
- **典型参数**：β = 0.9

**自适应学习率方法**

1. **AdaGrad**
   - 对稀疏特征友好
   - 学习率会逐渐减小
   - 可能过早停止学习

2. **RMSprop**
   - 解决AdaGrad学习率消失问题
   - 使用指数衰减平均
   - 适合非平稳目标

3. **Adam**
   - 结合动量和RMSprop
   - 自适应学习率
   - 目前最常用的优化器
   - 算法：
     ```
     m = β₁m + (1-β₁)g      # 一阶矩估计
     v = β₂v + (1-β₂)g²     # 二阶矩估计
     m̂ = m / (1-β₁ᵗ)        # 偏差修正
     v̂ = v / (1-β₂ᵗ)        # 偏差修正
     θ = θ - η × m̂ / (√v̂ + ε)
     ```

#### 4.3 拉格朗日乘数法

**等式约束优化**

- **问题**：
  ```
  minimize    f(x)
  subject to  h(x) = 0
  ```
- **拉格朗日函数**：L(x, λ) = f(x) + λh(x)
- **最优性条件**：
  - ∇ₓL = 0
  - ∇ₓL = 0
  - h(x) = 0

**不等式约束优化**

- **KKT条件**：
  - ∇ₓL = 0
  - gᵢ(x) ≤ 0
  - μᵢ ≥ 0
  - μᵢgᵢ(x) = 0（互补松弛条件）

**在AI中的应用**：
- SVM对偶问题：通过拉格朗日对偶得到
- 带约束的优化：正则化、资源限制
- 模型压缩：在精度约束下最小化模型大小

#### 4.4 优化理论在AI中的综合应用

1. **模型训练**
   - 损失函数设计：MSE、交叉熵、自定义损失
   - 正则化：L1（稀疏性）、L2（权重衰减）
   - 早停法：防止过拟合

2. **超参数调优**
   - 网格搜索：遍历所有组合
   - 随机搜索：随机采样超参数
   - 贝叶斯优化：建立代理模型指导搜索

3. **高级优化技巧**
   - 学习率预热：开始时小学习率，逐渐增大
   - 余弦退火：学习率按余弦曲线衰减
   - 梯度裁剪：防止梯度爆炸
   - 混合精度训练：使用FP16加速训练

4. **分布式优化**
   - 数据并行：不同设备处理不同数据
   - 模型并行：不同设备处理模型不同部分
   - 异步更新：减少通信开销

```python
def numerical_derivative(f, x, h=1e-5):
    return (f(x + h) - f(x - h)) / (2 * h)

# 梯度下降
def gradient_descent(f, grad_f, x0, learning_rate=0.01, n_iter=100):
    x = x0
    history = [x]
    for i in range(n_iter):
        grad = grad_f(x)
        x = x - learning_rate * grad
        history.append(x)
    return x, history

# 示例：最小化 f(x) = x^2
```

```python
# Adam优化器
class Adam:
    def __init__(self, learning_rate=0.001, beta1=0.9, beta2=0.999, epsilon=1e-8):
        self.lr = learning_rate
        self.beta1 = beta1
        self.beta2 = beta2
        self.epsilon = epsilon
        self.m = None
        self.v = None
        self.t = 0
    
    def update(self, params, grads):
        if self.m is None:
            self.m = np.zeros_like(params)
            self.v = np.zeros_like(params)
        
        self.t += 1
        self.m = self.beta1 * self.m + (1 - self.beta1) * grads
        self.v = self.beta2 * self.v + (1 - self.beta2) * grads**2
        
        m_hat = self.m / (1 - self.beta1**self.t)
        v_hat = self.v / (1 - self.beta2**self.t)
        
        params = params - self.lr * m_hat / (np.sqrt(v_hat) + self.epsilon)
        return params

# 使用示例
optimizer = Adam(learning_rate=0.001)
params = np.array([1.0, 2.0, 3.0])
grads = np.array([0.1, 0.2, 0.3])
params = optimizer.update(params, grads)
```

   - 线性代数：向量、矩阵、特征值
   - 概率统计：贝叶斯定理、正态分布、假设检验
   - 微积分：导数、梯度、梯度下降
   - 优化：SGD、Adam

2. **学习-实践-学习循环**：
   - 学习概念 → 编程实现 → 应用到AI问题 → 发现不足 → 补充学习

3. **利用优质资源**：
   - 3Blue1Brown的视频（直觉培养）
   - Khan Academy（基础巩固）
   - NumPy官方教程（编程实践）

### Q9: 遇到数学符号看不懂怎么办？

**A**: 建议：

1. **建立符号表**：记录常见符号及其含义
2. **从例子理解**：通过具体例子理解抽象符号
3. **可视化工具**：使用GeoGebra等工具可视化
4. **查阅资料**：Wolfram MathWorld有详细解释
5. **不要纠结**：先理解思想，细节以后再补

常见符号速查：
- Σ：求和
- Π：连乘
- ∂：偏导数
- ∇：梯度
- ∈：属于
- ∀：对于所有
- ∃：存在
