# AI学习路线图 - 经典机器学习算法

## 学习目标

本阶段旨在帮助有机器学习基础的学习者深入掌握经典机器学习算法的核心原理、实现细节和实际应用。通过系统学习，您将能够：

- **深入理解决策树与集成学习**：掌握决策树的构建原理、剪枝技术，以及Bagging、Boosting等集成学习策略
- **掌握支持向量机(SVM)**：理解最大间隔分类、核技巧和SVM在分类与回归问题中的应用
- **学会贝叶斯分类器**：掌握贝叶斯定理、朴素贝叶斯分类器及其变体，理解贝叶斯网络和贝叶斯优化
- **理解时间序列分析**：学习时间序列数据的特性分析、经典预测方法和机器学习在时间序列中的应用

## 学习内容

### 1. 决策树与集成学习 (3-4周)

#### 决策树深入

决策树是一种基于树结构进行决策的监督学习算法，具有直观易懂、可解释性强的特点。在本部分，我们将深入探讨决策树的核心算法和技术。

**ID3算法**：ID3（Iterative Dichotomiser 3）是最早提出的决策树算法之一，由Ross Quinlan在1986年提出。该算法使用信息增益作为特征选择的标准，通过递归地构建决策树来解决分类问题。ID3算法的核心思想是：在每个节点选择能够最大程度减少数据集不确定性的特征。信息增益的计算基于信息熵的概念，熵是衡量数据集混乱程度的指标。ID3算法的优点是简单直观，但存在明显缺点：倾向于选择取值较多的特征，容易过拟合，且无法处理连续特征和缺失值。

**C4.5算法**：C4.5是ID3的改进版本，同样由Ross Quinlan提出。C4.5算法主要解决了ID3的几个关键问题：首先，使用信息增益比（Gain Ratio）代替信息增益，避免了ID3偏向多值特征的问题；其次，能够处理连续特征，通过寻找最佳分割点将连续特征离散化；第三，能够处理缺失值，通过概率权重的方式处理缺失数据；最后，引入了剪枝机制，包括预剪枝和后剪枝，有效控制过拟合。C4.5算法在工业界和学术界都得到了广泛应用。

**CART算法**：CART（Classification and Regression Trees）是由Breiman等人在1984年提出的决策树算法。CART算法具有几个显著特点：首先，生成的是二叉树，每个节点只有两个分支，这简化了决策规则；其次，能够同时处理分类和回归问题；第三，使用基尼系数（Gini Index）作为特征选择标准，而不是信息增益。CART算法在sklearn中得到了广泛实现，是目前最常用的决策树算法之一。

**基尼系数**：基尼系数是衡量数据集不纯度的重要指标，其取值范围在0到1之间。当数据集完全纯净（所有样本属于同一类别）时，基尼系数为0；当数据集完全混乱（各类别样本数量相等）时，基尼系数最大。基尼系数的计算公式为：Gini(D) = 1 - Σ(pi²)，其中pi是第i类样本在数据集中的比例。在构建决策树时，我们选择使基尼系数减少最多的特征进行分裂，这与信息增益的思想类似，但计算更加简单。

**回归树**：回归树是决策树在回归问题上的扩展。与分类树使用基尼系数或信息增益不同，回归树使用均方误差（MSE）或平均绝对误差（MAE）作为分裂标准。回归树的预测结果是叶子节点中所有训练样本目标值的平均值。回归树的构建过程包括：计算每个特征的最佳分割点，选择使误差减少最多的特征和分割点，递归地构建左右子树。回归树的优点是能够处理非线性关系，缺点是容易过拟合，通常需要与集成学习方法结合使用。

#### 集成学习

集成学习是通过组合多个学习器来提高预测性能的机器学习范式。其核心思想是"三个臭皮匠，顶个诸葛亮"，通过组合多个弱学习器构建强学习器。

**Bagging（Bootstrap Aggregating）**：Bagging是Leo Breiman在1996年提出的集成学习方法。其核心思想是：通过对训练数据进行有放回抽样（Bootstrap），生成多个不同的训练子集，在每个子集上训练一个基学习器，最后通过投票（分类）或平均（回归）的方式组合多个基学习器的预测结果。Bagging的主要优点是能够显著降低模型的方差，提高泛化能力，特别适用于高方差的模型（如决策树）。Bagging的代表算法是随机森林。

**Boosting**：Boosting是一类将弱学习器提升为强学习器的集成学习算法。与Bagging的并行训练不同，Boosting是串行训练的，每个新的基学习器都试图纠正前一个基学习器的错误。Boosting的基本思想是：为每个训练样本分配权重，初始时所有样本权重相等；在每轮训练中，增加被错误分类样本的权重，减少正确分类样本的权重；最后，将所有基学习器进行加权组合。Boosting的代表算法包括AdaBoost、Gradient Boosting等。

**Stacking**：Stacking是一种通过元学习器组合多个不同学习器的集成方法。Stacking的基本思想是：首先训练多个不同的基学习器（如决策树、SVM、KNN等），然后将这些基学习器的输出作为新的特征，训练一个元学习器（通常使用逻辑回归或简单神经网络）来进行最终预测。Stacking的优点是能够充分利用不同学习器的多样性，缺点是计算复杂度较高，且容易过拟合。在实际应用中，通常使用交叉验证来生成元特征，避免信息泄露。

#### 随机森林

随机森林是Bagging的一个重要扩展，由Leo Breiman在2001年提出。它通过在决策树的构建过程中引入随机性，进一步提高了集成模型的性能。

**原理**：随机森林的核心思想是构建多棵决策树，并通过投票或平均的方式组合它们的预测结果。与传统Bagging相比，随机森林在每次分裂时不是考虑所有特征，而是随机选择一部分特征（通常为总特征数的平方根），然后从这些特征中选择最佳分裂特征。这种双重随机性（样本随机和特征随机）使得随机森林具有很好的抗过拟合能力。

**特征重要性**：随机森林能够评估特征的重要性，这是其重要优点之一。特征重要性的计算方法主要有两种：基于不纯度减少（Gini Importance）和基于排列重要性（Permutation Importance）。基于不纯度减少的方法计算每个特征在所有树中分裂时带来的不纯度减少的平均值；基于排列重要性的方法通过随机打乱某个特征的值，观察模型性能的下降程度来评估特征重要性。特征重要性在特征选择、模型解释和业务理解中都有重要应用。

**参数调优**：随机森林的主要参数包括：n_estimators（树的数量）、max_depth（树的最大深度）、min_samples_split（内部节点再划分所需最小样本数）、min_samples_leaf（叶子节点最少样本数）、max_features（每次分裂考虑的最大特征数）等。参数调优通常使用网格搜索（Grid Search）或随机搜索（Random Search）结合交叉验证进行。一般来说，增加树的数量可以提高性能但会增加计算成本，适当限制树的深度可以防止过拟合。

#### Gradient Boosting

Gradient Boosting是一种强大的集成学习算法，通过迭代地训练新的基学习器来纠正前一个基学习器的残差，在机器学习竞赛和实际应用中都表现出色。

**XGBoost**：XGBoost（eXtreme Gradient Boosting）是陈天奇在2016年提出的梯度提升算法实现。XGBoost在传统Gradient Boosting的基础上进行了多项优化：首先，使用二阶泰勒展开近似损失函数，提高了优化效率；其次，加入了正则化项（L1和L2正则化），控制模型复杂度；第三，支持并行计算，大大提高了训练速度；第四，内置处理缺失值的能力；第五，提供了交叉验证和早停机制。XGBoost在Kaggle竞赛和工业界都得到了广泛应用。

**LightGBM**：LightGBM是微软在2017年提出的梯度提升框架。LightGBM的主要创新包括：首先，使用基于梯度的单边采样（GOSS）和互斥特征捆绑（EFB）技术，大大减少了训练数据量和特征数量；其次，采用Leaf-wise（按叶子增长）的生长策略，而不是传统的Level-wise（按层增长），能够在相同叶子数量下获得更低的损失；第三，支持类别特征直接输入，无需独热编码；第四，内存占用更低，训练速度更快。LightGBM特别适合大规模数据和高维特征的场景。

**CatBoost**：CatBoost是Yandex在2017年提出的梯度提升算法。CatBoost的主要特点包括：首先，能够很好地处理类别特征，使用Ordered Target Statistics方法避免目标泄露；其次，使用Ordered Boosting方法，减少梯度估计的偏差；第三，提供了内置的过拟合检测和处理机制；第四，支持GPU训练，进一步提高训练速度。CatBoost在处理类别特征丰富的数据集时表现优异。

### 2. 支持向量机(SVM) (2-3周)

支持向量机（Support Vector Machine, SVM）是一种强大的监督学习算法，特别适合处理小样本、高维数据和非线性分类问题。

#### 线性SVM

**最大间隔**：线性SVM的核心思想是找到能够将两类数据分开的最优超平面。最优超平面的定义是：使得离超平面最近的样本点（支持向量）到超平面的距离最大化。这个距离被称为间隔（Margin）。最大间隔分类器具有很好的泛化能力，因为它是基于结构风险最小化原则，而不是经验风险最小化。从数学角度，SVM可以转化为一个凸优化问题，存在全局最优解。

**支持向量**：支持向量是离决策边界最近的训练样本点，它们决定了决策边界的位置和方向。支持向量的特点是：它们是最难分类的样本点，也是对模型最重要的样本点。在预测时，只需要支持向量的信息，其他样本点可以丢弃。这使得SVM具有稀疏性，计算效率较高。

**软间隔**：在实际应用中，数据往往不是线性可分的，或者存在噪声和异常值。软间隔SVM通过引入松弛变量（Slack Variables）和惩罚参数C，允许一些样本点违反间隔约束。惩罚参数C控制了误分类的容忍度：C越大，对误分类的惩罚越大，模型越复杂；C越小，对误分类的容忍度越高，模型越简单。软间隔SVM在保持最大间隔的同时，提高了模型的鲁棒性。

#### 非线性SVM

**核技巧**：对于非线性可分的数据，SVM使用核技巧将数据映射到高维空间，使得在高维空间中数据变得线性可分。核技巧的核心思想是：不需要显式地计算高维空间的坐标，只需要计算样本之间的内积，这可以通过核函数高效完成。核技巧使得SVM能够在高维空间中构建线性分类器，而不需要承担高维计算的代价。

**常用核函数**：SVM常用的核函数包括：
- **线性核**：K(x, y) = x^T y，适用于线性可分的数据
- **多项式核**：K(x, y) = (γx^T y + r)^d，适用于多项式关系的数据
- **高斯核（RBF核）**：K(x, y) = exp(-γ||x - y||²)，适用于大多数非线性数据
- **Sigmoid核**：K(x, y) = tanh(γx^T y + r)，类似神经网络的激活函数

**核函数选择**：核函数的选择对SVM性能有重要影响。一般来说，如果特征数量远大于样本数量，可以使用线性核；如果样本数量远大于特征数量，可以使用高斯核；如果不确定，可以先尝试高斯核。核函数的参数（如高斯核的γ）也需要通过交叉验证进行调优。在实际应用中，通常使用网格搜索来寻找最佳的核函数和参数组合。

#### SVM回归

SVM不仅可以用于分类问题，还可以用于回归问题。SVM回归（Support Vector Regression, SVR）的基本思想是：找到一个函数f(x)，使得所有训练样本的预测值与真实值之间的偏差不超过ε，同时函数尽可能平滑。SVR使用ε-不敏感损失函数，当预测误差小于ε时，损失为0；当预测误差大于ε时，损失为线性增长。SVR同样可以使用核技巧处理非线性回归问题。

#### SVM优缺点

**优点**：
- 在高维空间中表现良好，特别适合特征数量多的场景
- 使用核技巧可以处理非线性问题
- 具有很好的泛化能力，不容易过拟合
- 决策过程只依赖于支持向量，具有稀疏性
- 理论基础扎实，有严格的数学证明

**缺点**：
- 对大规模数据集训练时间较长，计算复杂度高
- 对参数选择和核函数选择敏感
- 对缺失数据和噪声敏感
- 不直接提供概率估计，需要通过Platt缩放等方法间接获得
- 模型解释性相对较差

### 3. 贝叶斯方法 (2周)

贝叶斯方法是基于贝叶斯定理的概率机器学习方法，具有坚实的概率理论基础，在不确定性建模和概率推理中具有独特优势。

#### 贝叶斯定理

贝叶斯定理是概率论中的基本定理，描述了在已知先验知识的情况下，如何根据新的证据更新对事件概率的估计。贝叶斯定理的数学表达式为：P(A|B) = P(B|A) * P(A) / P(B)，其中P(A|B)是后验概率，P(B|A)是似然函数，P(A)是先验概率，P(B)是证据。贝叶斯定理的核心思想是：我们可以通过结合先验知识和新的观测数据，不断更新我们对世界的认识。贝叶斯方法在机器学习中的应用非常广泛，包括分类、回归、聚类、降维等任务。

#### 朴素贝叶斯

朴素贝叶斯是基于贝叶斯定理和特征条件独立假设的分类算法。其核心假设是：给定类别标签，所有特征之间相互独立。这个假设在现实中往往不成立，但朴素贝叶斯在实际应用中仍然表现出色，特别是在文本分类和垃圾邮件过滤等领域。

**高斯朴素贝叶斯**：假设连续特征服从高斯分布（正态分布）。对于每个类别和每个特征，计算该特征在该类别下的均值和方差，然后使用高斯概率密度函数计算似然概率。高斯朴素贝叶斯适用于连续特征的分类问题，如鸢尾花分类等。

**多项式朴素贝叶斯**：假设特征服从多项式分布，适用于离散的计数特征。在文本分类中，特征通常是词频或TF-IDF值，多项式朴素贝叶斯能够很好地处理这种情况。多项式朴素贝叶斯有一个平滑参数α，用于处理零概率问题，通常使用拉普拉斯平滑（α=1）或Lidstone平滑。

**伯努利朴素贝叶斯**：假设特征服从伯努利分布（二项分布），适用于二值特征。在文本分类中，如果特征是词是否出现（而不是词频），可以使用伯努利朴素贝叶斯。伯努利朴素贝叶斯同样有平滑参数，用于处理零概率问题。

#### 贝叶斯网络

贝叶斯网络是一种概率图模型，用有向无环图（DAG）表示变量之间的条件依赖关系。贝叶斯网络的优点包括：能够处理不确定性、能够进行因果推理、能够结合专家知识、能够处理缺失数据。贝叶斯网络的学习包括结构学习和参数学习两部分。结构学习是确定变量之间的依赖关系，可以使用基于约束的方法（如PC算法）或基于评分的方法（如BIC评分）。参数学习是在给定结构的情况下，估计条件概率表，可以使用最大似然估计或贝叶斯估计。

#### 贝叶斯优化

贝叶斯优化是一种用于黑盒函数优化的序列设计策略，特别适用于评估代价高昂的优化问题。贝叶斯优化的核心思想是：使用代理模型（通常是高斯过程）来近似目标函数，然后使用采集函数来决定下一个评估点。贝叶斯优化在超参数调优、实验设计、强化学习等领域有重要应用。常用的采集函数包括：期望改善（Expected Improvement, EI）、置信上界（Upper Confidence Bound, UCB）、概率改善（Probability of Improvement, PI）等。

### 4. 时间序列分析 (2-3周)

时间序列分析是处理按时间顺序排列的数据的重要方法，在金融、经济、气象、工业等领域有广泛应用。

#### 时间序列基础

**趋势**：趋势是时间序列数据中长期的上升或下降模式。趋势可以是线性的，也可以是非线性的（如指数趋势、多项式趋势）。识别趋势的方法包括：移动平均、线性回归、多项式拟合等。趋势分析对于理解数据的长期行为和进行长期预测非常重要。

**季节性**：季节性是时间序列数据中固定周期的重复模式。季节性可以是年季节性（如零售业的季节性波动）、周季节性（如工作日与周末的差异）、日季节性（如一天内的温度变化）等。识别季节性的方法包括：自相关分析、傅里叶变换、季节性分解等。季节性调整是时间序列预处理的重要步骤。

**噪声**：噪声是时间序列数据中的随机波动，通常由不可预测的因素引起。噪声会掩盖真实的数据模式，影响预测准确性。处理噪声的方法包括：平滑技术（如移动平均、指数平滑）、滤波技术（如卡尔曼滤波）、小波去噪等。在建模前，通常需要评估噪声水平，选择合适的去噪方法。

#### 经典方法

**移动平均**：移动平均是最简单的时间序列平滑方法，通过计算相邻数据点的平均值来减少噪声。常见的移动平均方法包括：简单移动平均（SMA）、加权移动平均（WMA）、指数移动平均（EMA）。移动平均的窗口大小是重要参数，较大的窗口平滑效果更好，但会丢失更多细节。移动平均还可以用于识别趋势和季节性。

**指数平滑**：指数平滑是一类重要的时间序列预测方法，通过赋予不同时间点的观测值不同的权重来进行预测。常见的指数平滑方法包括：简单指数平滑（适用于无趋势无季节性数据）、Holt线性趋势方法（适用于有趋势数据）、Holt-Winters季节性方法（适用于有趋势和季节性数据）。指数平滑的参数（平滑系数）通常通过最小化预测误差来估计。

**ARIMA**：ARIMA（自回归积分移动平均模型）是时间序列分析中最经典的模型之一。ARIMA模型由三部分组成：AR（自回归）部分、I（差分）部分、MA（移动平均）部分。ARIMA模型的建立包括：识别阶段（确定p、d、q参数）、估计阶段（估计模型参数）、诊断阶段（检验模型残差）。ARIMA模型适用于平稳时间序列，对于非平稳时间序列，需要先进行差分处理。SARIMA是ARIMA的扩展，能够处理季节性时间序列。

#### 机器学习方法

**特征工程**：在机器学习方法中，特征工程是时间序列预测的关键步骤。常用的时间序列特征包括：滞后特征（Lag Features）、滚动统计特征（Rolling Statistics）、日期时间特征（如星期几、月份、季节等）、傅里叶特征（用于捕捉周期性）、技术指标（如移动平均、RSI等，在金融领域）。特征工程需要结合领域知识，创造能够捕捉时间序列模式的特征。

**模型选择**：适用于时间序列预测的机器学习模型包括：线性回归、随机森林、梯度提升树（XGBoost、LightGBM）、支持向量回归（SVR）、神经网络（如LSTM、GRU）等。模型选择需要考虑数据量、数据特性、预测 horizon、计算资源等因素。通常建议先尝试简单模型（如线性回归），再尝试复杂模型（如梯度提升树），最后考虑深度学习模型。

**预测评估**：时间序列预测的评估指标包括：均方误差（MSE）、均方根误差（RMSE）、平均绝对误差（MAE）、平均绝对百分比误差（MAPE）、对称平均绝对百分比误差（SMAPE）等。评估时需要注意：时间序列数据具有时间依赖性，不能使用随机交叉验证，而应该使用时间序列交叉验证（如滚动预测原点交叉验证）。此外，还需要考虑预测的稳定性和鲁棒性。

## 常见问题

### Q1: 决策树容易过拟合，如何解决？
**A**: 决策树过拟合是常见问题，可以通过以下方法解决：
1. **预剪枝**：在构建树的过程中提前停止，如限制树的最大深度、叶子节点最小样本数、内部节点最小样本数等
2. **后剪枝**：先构建完整的树，然后通过代价复杂度剪枝（Cost-Complexity Pruning）删除不必要的分支
3. **集成学习**：使用随机森林、梯度提升等集成方法，通过组合多棵树来降低方差
4. **特征选择**：选择最相关的特征，减少噪声特征的影响
5. **增加训练数据**：更多的数据可以帮助模型学习到更一般的模式

### Q2: SVM在什么情况下比逻辑回归更好？
**A**: SVM在以下情况下通常比逻辑回归表现更好：
1. **高维数据**：当特征数量远大于样本数量时，SVM的泛化能力通常更好
2. **小样本数据**：在小数据集上，SVM的最大间隔原理有助于避免过拟合
3. **非线性问题**：通过核技巧，SVM可以处理复杂的非线性决策边界
4. **关注支持向量**：当决策边界主要由少数关键样本点决定时，SVM的稀疏性更有优势
5. **内存效率**：在大规模数据集上，SVM的预测速度可能更快，因为只需要存储支持向量

### Q3: 朴素贝叶斯的条件独立假设在现实中不成立，为什么还能工作？
**A**: 朴素贝叶斯虽然假设特征条件独立，但在实际应用中仍然有效，原因包括：
1. **分类任务的特点**：分类任务只需要估计后验概率的相对大小，而不是精确概率。即使特征相关性导致概率估计不准确，但只要排序正确，分类结果就可能是正确的
2. **正则化效果**：条件独立假设起到了正则化的作用，减少了模型的方差，避免了过拟合
3. **数据充分时**：当训练数据足够多时，即使特征相关，朴素贝叶斯也能获得很好的性能
4. **高维数据**：在高维数据中，特征之间的相关性可能被稀释，条件独立假设的影响减小
5. **平滑技术**：通过拉普拉斯平滑等技术，可以缓解零概率问题，提高模型的鲁棒性

### Q4: 如何选择合适的时间序列模型？
**A**: 选择时间序列模型需要考虑以下因素：
1. **数据特性**：
   - 平稳性：平稳数据可以使用ARMA模型，非平稳数据需要先差分或使用ARIMA
   - 季节性：有季节性数据使用SARIMA或Holt-Winters季节性方法
   - 趋势：有趋势数据使用Holt线性趋势方法或ARIMA
2. **预测目标**：
   - 短期预测：可以使用指数平滑、ARIMA
   - 长期预测：可能需要考虑机器学习方法或深度学习
3. **计算资源**：
   - 简单模型：指数平滑、ARIMA
   - 复杂模型：机器学习方法、深度学习
4. **可解释性要求**：
   - 高可解释性：指数平滑、ARIMA
   - 低可解释性：深度学习方法

### Q5: 集成学习中，Bagging和Boosting的主要区别是什么？
**A**: Bagging和Boosting是两种主要的集成学习策略，主要区别包括：
1. **训练方式**：
   - Bagging：并行训练，每个基学习器独立训练
   - Boosting：串行训练，每个新的基学习器都依赖于前一个
2. **数据采样**：
   - Bagging：有放回抽样（Bootstrap），样本权重相同
   - Boosting：通常使用全部数据，但调整样本权重
3. **基学习器组合**：
   - Bagging：投票（分类）或平均（回归），权重相同
   - Boosting：加权组合，根据基学习器性能分配权重
4. **目标**：
   - Bagging：主要降低方差，提高稳定性
   - Boosting：主要降低偏差，提高准确性
5. **过拟合风险**：
   - Bagging：不容易过拟合
   - Boosting：容易过拟合，需要早停或正则化

### Q6: 如何处理时间序列中的缺失值？
**A**: 时间序列中缺失值的处理方法包括：
1. **删除法**：如果缺失值比例很小，可以直接删除
2. **插值法**：
   - 线性插值：适用于趋势平稳的数据
   - 样条插值：适用于平滑变化的数据
   - 季节性插值：适用于有季节性的数据
3. **移动平均法**：使用前后窗口的平均值填充
4. **预测法**：使用时间序列模型预测缺失值
5. **机器学习方法**：使用KNN、随机森林等模型预测缺失值
6. **特殊处理**：某些模型（如XGBoost）可以直接处理缺失值

### Q7: 如何评估时间序列预测模型的性能？
**A**: 时间序列预测模型的评估需要注意：
1. **评估指标**：
   - 误差指标：MSE、RMSE、MAE、MAPE、SMAPE
   - 方向准确性：预测趋势是否正确
   - 覆盖率：预测区间是否包含真实值
2. **评估方法**：
   - 时间序列交叉验证：使用滚动预测原点（Rolling Origin Cross-Validation）
   - 固定划分：按时间顺序划分训练集和测试集
   - 前向验证：模拟实际预测场景
3. **基准模型**：
   - 朴素模型：使用季节性朴素预测或平均值预测
   - 简单模型：使用指数平滑或ARIMA作为基准
4. **统计检验**：
   - Diebold-Mariano检验：比较两个预测模型的性能差异
   - 预测误差的自相关检验：检查误差是否包含可预测的模式

### Q8: 在实际项目中，如何选择机器学习算法？
**A**: 选择机器学习算法需要考虑多个因素：
1. **问题类型**：
   - 分类问题：逻辑回归、SVM、决策树、随机森林、XGBoost
   - 回归问题：线性回归、随机森林回归、XGBoost回归、SVR
   - 聚类问题：K-means、DBSCAN、层次聚类
2. **数据特性**：
   - 数据量：小数据集适合SVM、朴素贝叶斯；大数据集适合随机森林、XGBoost
   - 特征类型：连续特征适合线性模型；混合特征适合树模型
   - 数据质量：有噪声数据适合集成方法；干净数据可以使用简单模型
3. **业务需求**：
   - 可解释性：决策树、逻辑回归具有较好的可解释性
   - 训练速度：线性模型、朴素贝叶斯训练速度快
   - 预测速度：线性模型、决策树预测速度快
4. **资源限制**：
   - 计算资源：深度学习需要GPU；传统方法可以在CPU上运行
   - 存储资源：集成模型可能需要更多存储空间
   - 时间限制：项目时间紧张可以选择快速实现的算法
