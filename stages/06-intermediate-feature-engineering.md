# AI学习路线图 - 特征工程

## 学习目标

特征工程是机器学习流程中至关重要的一环，它直接影响模型的性能和泛化能力。通过本阶段的学习，你将能够：

- **理解特征工程的重要性**：认识到"数据和特征决定了机器学习的上限，而模型和算法只是逼近这个上限"
- **掌握数值特征处理**：学会处理缺失值、异常值、特征缩放和变换等关键技术
- **掌握类别特征处理**：熟练运用各种编码方法将类别数据转换为数值表示
- **学会文本特征提取**：掌握从文本数据中提取有效特征的方法
- **掌握特征选择方法**：学会从大量特征中筛选出最有价值的特征子集

## 学习内容

### 1. 特征工程概述 (1周)

#### 1.1 什么是特征工程

特征工程（Feature Engineering）是将原始数据转换为更适合机器学习模型使用的特征的过程。它是数据科学和机器学习中的核心技能，通常需要花费数据科学家60%-80%的时间。特征工程的目标是提高模型的预测能力、降低计算复杂度、增强模型的可解释性。

在实际项目中，原始数据往往包含大量噪声、缺失值、异常值，且数据格式可能不适合直接输入模型。特征工程就是对这些原始数据进行清洗、转换、组合，创造出能够更好表示数据内在规律的新特征。这个过程既需要技术能力，也需要对业务领域的深入理解。

#### 1.2 特征工程的重要性

特征工程的重要性体现在以下几个方面：

**提升模型性能**：好的特征能够显著提升模型的准确率。在Kaggle等数据科学竞赛中，顶尖选手往往不是使用最复杂的模型，而是通过精妙的特征工程获得优势。

**降低模型复杂度**：通过特征工程可以减少特征数量，降低模型的计算复杂度，提高训练和推理速度。

**增强模型泛化能力**：合理的特征工程可以帮助模型更好地捕捉数据的本质规律，而不是学习到噪声和偶然关联，从而提高模型在新数据上的表现。

**提高模型可解释性**：通过构建业务含义明确的特征，可以使模型的预测结果更容易理解和解释。

#### 1.3 特征工程工作流程

一个完整的特征工程工作流程通常包括以下步骤：

1. **数据理解**：深入了解数据的来源、含义、分布和质量
2. **数据清洗**：处理缺失值、异常值、重复值等问题
3. **特征转换**：将原始特征转换为更适合模型的形式
4. **特征构建**：基于领域知识和数据关系创建新特征
5. **特征选择**：从所有特征中筛选出最有价值的子集
6. **特征评估**：评估特征工程的效果，迭代优化

#### 1.4 特征工程与领域知识

特征工程不仅仅是技术活，更需要深入理解业务领域。不同领域的特征工程策略差异很大：

- **金融领域**：需要理解金融指标、风险因素、市场规律
- **医疗领域**：需要医学知识来理解和处理临床数据
- **电商领域**：需要理解用户行为、商品属性、交易特征
- **自然语言处理**：需要语言学知识来设计文本特征

领域知识可以帮助我们：
- 识别哪些原始数据是有价值的
- 理解特征之间的业务逻辑关系
- 设计具有业务含义的衍生特征
- 避免构建没有实际意义的特征

### 2. 数值特征处理 (2周)

#### 2.1 缺失值处理

缺失值是实际数据中最常见的问题之一。处理缺失值的方法主要有以下几种：

**删除法**：
- **删除行**：当缺失值比例较低（如<5%）且数据量充足时，可以直接删除包含缺失值的样本
- **删除列**：当某个特征的缺失值比例过高（如>50%）时，可以考虑删除整个特征
- 优点：简单快速
- 缺点：可能丢失有价值的信息，特别是当缺失不是随机发生时

**统计值填充**：
- **均值填充**：适用于正态分布的数据，对异常值敏感
- **中位数填充**：适用于偏态分布的数据，对异常值更鲁棒
- **众数填充**：适用于类别型数据或离散型数值数据
- 优点：实现简单，保留了数据集的大小
- 缺点：可能引入偏差，忽略了特征之间的关系

**模型预测填充**：
- 使用其他特征作为输入，训练模型来预测缺失值
- 常用模型：KNN、随机森林、线性回归等
- 优点：考虑了特征之间的关系，可能更准确
- 缺点：计算复杂度较高，可能过拟合

**KNN填充**：
- 找到与缺失样本最相似的K个样本，用它们的平均值填充
- 优点：考虑了数据的局部结构
- 缺点：对K值敏感，计算复杂度高

**多重插补（Multiple Imputation）**：
- 生成多个填充版本，分别建模后综合结果
- 能够反映填充的不确定性
- 统计上更严谨，但实现复杂

#### 2.2 异常值处理

异常值可能是数据错误，也可能是真实但罕见的情况。处理方法包括：

**Z-score方法**：
- 计算每个数据点与均值的标准差距离
- 通常将|Z-score|>3的数据点视为异常值
- 适用于正态分布的数据
- 公式：Z = (X - μ) / σ

**IQR方法（四分位距法）**：
- 计算第一四分位数Q1和第三四分位数Q3
- IQR = Q3 - Q1
- 将小于Q1-1.5*IQR或大于Q3+1.5*IQR的数据点视为异常值
- 对非正态分布数据更鲁棒

**孤立森林（Isolation Forest）**：
- 基于树的集成方法，专门用于异常检测
- 异常点由于数量少且特征值特殊，更容易被"孤立"
- 适用于高维数据，不需要假设数据分布
- 可以处理大量数据，效率较高

**DBSCAN聚类**：
- 基于密度的聚类方法，将不属于任何簇的点视为异常值
- 不需要预先指定簇的数量
- 可以发现任意形状的簇

处理异常值的策略：
- **删除**：当确定是数据错误时
- **替换**：用边界值替换（如用99%分位数替换极端值）
- **转换**：对数变换、平方根变换等可以压缩异常值的影响
- **单独建模**：如果异常值有特殊含义，可以单独处理

#### 2.3 特征缩放

不同特征的量纲和取值范围可能差异很大，特征缩放可以使它们处于相同的尺度：

**标准化（Standardization）**：
- 公式：X_scaled = (X - μ) / σ
- 转换后数据均值为0，标准差为1
- 适用于：大多数机器学习算法，特别是基于距离的算法（如SVM、KNN）和梯度下降优化的算法
- 优点：保留了异常值的信息，对异常值相对鲁棒

**归一化（Min-Max Normalization）**：
- 公式：X_scaled = (X - X_min) / (X_max - X_min)
- 将数据压缩到[0,1]区间
- 适用于：神经网络、需要输入在固定范围内的算法
- 缺点：对异常值非常敏感，异常值会压缩正常数据的范围

**鲁棒缩放（Robust Scaling）**：
- 使用中位数和四分位距进行缩放
- 公式：X_scaled = (X - median) / IQR
- 对异常值非常鲁棒
- 适用于：数据中存在较多异常值的情况

**最大绝对值缩放**：
- 公式：X_scaled = X / max(|X|)
- 将数据缩放到[-1,1]区间
- 适用于稀疏数据，因为它保留了数据的稀疏性

#### 2.4 特征变换

特征变换可以改变数据的分布，使其更符合模型的假设：

**对数变换**：
- 公式：X_transformed = log(X) 或 log(X+1)
- 适用于右偏分布的数据
- 可以压缩大值，拉伸小值
- 注意：只能用于正值数据，零值需要加1

**Box-Cox变换**：
- 参数化的幂变换，可以自动找到最优的变换参数
- 公式：Y = (X^λ - 1) / λ（当λ≠0），Y = log(X)（当λ=0）
- 要求数据为正值
- 目标是使数据尽可能接近正态分布

**Yeo-Johnson变换**：
- Box-Cox变换的扩展，可以处理负值和零值
- 适用范围更广
- 同样是参数化的变换，通过优化找到最优参数

**平方根变换**：
- 适用于计数数据或轻度右偏的数据
- 比对数变换更温和
- 可以处理零值

**分位数变换**：
- 将数据映射到指定的分布（如均匀分布或正态分布）
- 基于数据的分位数进行转换
- 对异常值非常鲁棒，但可能改变数据的相对关系

### 3. 类别特征处理 (2周)

#### 3.1 编码方法

类别特征需要转换为数值形式才能被机器学习模型使用：

**独热编码（One-Hot Encoding）**：
- 为每个类别创建一个二进制特征
- 优点：不引入类别间的顺序关系，适用于无序类别
- 缺点：当类别数量很多时，会导致特征维度爆炸（高基数问题）
- 实现：pandas的get_dummies()或sklearn的OneHotEncoder

**标签编码（Label Encoding）**：
- 将每个类别映射为一个整数
- 优点：简单，不增加特征维度
- 缺点：引入了类别间的顺序关系，可能误导模型
- 适用于：有序类别（如教育程度：小学、初中、高中）
- 不适用于：无序类别（如颜色：红、绿、蓝）

**目标编码（Target Encoding）**：
- 用每个类别对应的目标变量的统计值（如均值）来编码
- 优点：可以处理高基数类别，编码后维度不变
- 缺点：容易过拟合，需要使用交叉验证或平滑技术
- 平滑公式：encoding = (count * mean_category + m * mean_global) / (count + m)
- 其中m是平滑参数，count是类别样本数

**频率编码（Frequency Encoding）**：
- 用每个类别出现的频率来编码
- 优点：简单，可以反映类别的普遍程度
- 缺点：不同类别可能有相同的频率

**哈希编码（Hash Encoding）**：
- 使用哈希函数将类别映射到固定维度的向量
- 优点：可以处理高基数类别，维度可控
- 缺点：可能存在哈希冲突，编码后的特征可解释性差

**证据权重编码（WOE - Weight of Evidence）**：
- 常用于信用评分领域
- 公式：WOE = ln(坏样本比例/好样本比例)
- 可以将非线性关系转换为线性关系

#### 3.2 高基数类别处理

高基数类别（High Cardinality）是指类别数量很多的情况，如用户ID、邮政编码等：

**特征组合**：
- 将相关类别组合成新特征
- 例如：将城市和区县组合成"城市-区县"
- 可以降低基数，同时保留重要信息

**嵌入编码（Embedding）**：
- 使用神经网络学习类别的低维稠密表示
- 类似于Word2Vec的思想
- 优点：可以捕捉类别之间的语义关系
- 缺点：需要足够的数据来学习

**频率分组**：
- 将低频类别合并为"其他"类别
- 例如：出现次数少于10次的类别合并为"other"
- 简单有效，但可能丢失信息

**目标编码的变体**：
- 使用留一法（Leave-One-Out）编码避免信息泄露
- 使用K折交叉验证编码
- 添加噪声防止过拟合

#### 3.3 有序类别处理

有序类别是指有内在顺序的类别变量：

**顺序编码**：
- 根据类别顺序分配整数
- 例如：教育程度 - 小学:1, 初中:2, 高中:3, 大学:4
- 保留了类别间的顺序关系

**多项式编码**：
- 可以捕捉类别间的非线性关系
- 例如：使用二次或三次多项式特征

**自定义映射**：
- 根据业务知识设置编码值
- 例如：满意度 - 非常不满意:1, 不满意:3, 中立:5, 满意:7, 非常满意:9

### 4. 文本特征提取 (2-3周)

#### 4.1 词袋模型

词袋模型（Bag of Words）是最基础的文本表示方法：

**CountVectorizer**：
- 统计每个词在文档中出现的次数
- 将文本转换为词频向量
- 参数：
  - max_features：限制词汇表大小
  - min_df/max_df：过滤过高或过低频率的词
  - ngram_range：考虑的n-gram范围
- 优点：简单直观
- 缺点：忽略了词序和上下文

**TF-IDF（词频-逆文档频率）**：
- TF（词频）：词在当前文档中出现的频率
- IDF（逆文档频率）：衡量词的普遍重要性，log(文档总数/包含该词的文档数)
- TF-IDF = TF × IDF
- 优点：降低了常见词的权重，提高了有区分度的词的权重
- 适用场景：文本分类、信息检索、关键词提取

#### 4.2 N-gram

N-gram是连续N个词的序列：

**Unigram (N=1)**：单个词，最基础的特征
**Bigram (N=2)**：连续两个词的组合，如"机器 学习"
**Trigram (N=3)**：连续三个词的组合，如"深度 学习 算法"

N-gram的优点：
- 可以捕捉局部词序信息
- 比单个词包含更多上下文
- 对于某些任务（如情感分析）效果更好

N-gram的缺点：
- 特征空间随N增大呈指数增长
- 高阶N-gram可能很稀疏
- 计算和存储开销大

实践建议：
- 通常使用unigram + bigram就足够了
- 对于短文本，可以考虑trigram
- 配合max_features参数控制特征数量

#### 4.3 词嵌入

词嵌入（Word Embedding）将词映射为低维稠密向量：

**Word2Vec**：
- 两种架构：CBOW（连续词袋）和Skip-gram
- CBOW：用上下文预测中心词，训练速度快
- Skip-gram：用中心词预测上下文，对低频词效果更好
- 优点：可以学习词之间的语义关系
- 经典例子：king - man + woman ≈ queen

**GloVe（Global Vectors）**：
- 基于全局词共现矩阵
- 结合了LSA和Word2Vec的优点
- 提供预训练词向量，维度有50d、100d、200d、300d
- 优点：利用了全局统计信息

**FastText**：
- Facebook开源的词向量工具
- 基于子词（subword）信息
- 可以为未登录词（OOV）生成向量
- 对于形态丰富的语言（如中文、德语）效果更好

**上下文相关词嵌入**：
- ELMo：基于双向LSTM，考虑上下文的词向量
- BERT：基于Transformer，预训练语言模型
- 可以处理一词多义的问题

#### 4.4 文本预处理

文本预处理是文本特征提取的基础：

**分词（Tokenization）**：
- 英文：按空格和标点分割
- 中文：需要专门的分词工具（如jieba、HanLP）
- 子词分词：BPE、WordPiece、SentencePiece

**停用词（Stop Words）**：
- 移除常见但信息量低的词（如"的"、"是"、"the"、"is"）
- 可以使用预定义的停用词表
- 注意：某些任务中停用词可能有用，需要根据具体情况决定

**词干提取（Stemming）和词形还原（Lemmatization）**：
- 词干提取：粗略地将词还原为词干（如"running"→"run"）
- 词形还原：基于词典的精确还原（如"better"→"good"）
- 目的：减少词汇表大小，合并相同词根的词

**其他预处理**：
- 转换为小写
- 移除标点符号和特殊字符
- 移除数字或将其转换为特殊标记
- 处理HTML标签和URL
- 纠错和拼写检查

### 5. 特征选择 (2周)

#### 5.1 过滤法

过滤法（Filter Methods）独立于机器学习模型，基于统计指标评估特征：

**方差阈值（Variance Threshold）**：
- 移除方差低于阈值的特征
- 假设：方差小的特征区分度低
- 优点：计算简单快速
- 缺点：只考虑单个特征，忽略了特征之间的关系

**相关系数（Correlation Coefficient）**：
- Pearson相关系数：衡量线性关系，适用于连续变量
- Spearman相关系数：衡量单调关系，适用于有序变量
- 移除与目标变量相关性低的特征
- 移除高度相关的特征对中的一个（避免多重共线性）

**卡方检验（Chi-Squared Test）**：
- 衡量类别特征与目标变量之间的独立性
- 适用于分类问题
- 卡方值越大，特征越重要
- 要求特征为非负值

**互信息（Mutual Information）**：
- 衡量特征与目标变量之间的信息共享量
- 可以捕捉非线性关系
- 适用于分类和回归问题
- 取值范围为[0, +∞)，值越大关系越强

**ANOVA F检验**：
- 衡量各组均值是否有显著差异
- 适用于分类问题，特征为连续变量
- 假设各组方差相等

#### 5.2 包装法

包装法（Wrapper Methods）使用机器学习模型评估特征子集：

**前向选择（Forward Selection）**：
- 从空集开始，每次添加一个最有价值的特征
- 直到性能不再提升或达到指定特征数
- 优点：简单，通常能找到好的特征子集
- 缺点：计算量大，可能陷入局部最优

**后向消除（Backward Elimination）**：
- 从所有特征开始，每次移除一个最不重要的特征
- 直到性能开始下降或达到指定特征数
- 优点：考虑了特征之间的交互
- 缺点：计算量大，初始特征多时耗时长

**递归特征消除（Recursive Feature Elimination, RFE）**：
- 训练模型，根据特征重要性排序
- 移除最不重要的特征，重复直到达到指定特征数
- 常与线性模型（如SVM、逻辑回归）或树模型配合使用
- sklearn提供了RFE和RFECV实现

**穷举搜索（Exhaustive Search）**：
- 评估所有可能的特征组合
- 可以找到全局最优解
- 计算复杂度是指数级的，只适用于特征数量很少的情况

#### 5.3 嵌入法

嵌入法（Embedded Methods）在模型训练过程中自动进行特征选择：

**L1正则化（Lasso）**：
- 在损失函数中添加L1惩罚项：λΣ|w|
- 可以将部分特征的权重压缩为0
- 自动实现特征选择
- λ越大，选择的特征越少
- 适用于线性模型

**树模型特征重要性**：
- 决策树、随机森林、GBDT等树模型可以计算特征重要性
- 常用指标：
  - 基于不纯度：特征在树中分裂时带来的不纯度减少
  - 基于排列：打乱特征值后模型性能的下降程度
- 优点：可以捕捉非线性关系和特征交互
- 注意：基于不纯度的方法可能偏向高基数特征

**Elastic Net**：
- 结合L1和L2正则化
- 可以处理特征之间的相关性
- 比Lasso更稳定

**基于模型的特征选择**：
- 使用任何模型的特征重要性进行选择
- 可以使用SelectFromModel类
- 灵活，可以与任何模型配合

### 6. 特征构建 (1-2周)

#### 6.1 交互特征

交互特征捕捉特征之间的相互作用：

**乘法交互**：
- 特征A × 特征B
- 例如：身高 × 体重
- 可以捕捉线性交互关系

**加法交互**：
- 特征A + 特征B
- 例如：总收入 = 工资 + 奖金

**除法交互**：
- 特征A / 特征B
- 例如：BMI = 体重 / 身高²
- 常用于创建比率特征

**多项式特征**：
- 使用sklearn的PolynomialFeatures
- 自动生成特征的高次项和交互项
- degree=2时生成：1, a, b, a², ab, b²
- 注意：可能导致维度爆炸，需要配合特征选择使用

#### 6.2 时间特征

时间数据包含丰富的信息，需要专门的特征构建：

**基本时间特征**：
- 年、月、日、小时、分钟、秒
- 星期几、一年中的第几周、一年中的第几天
- 是否周末、是否节假日、是否工作日

**时间差特征**：
- 距离某个基准时间的天数/小时数
- 用户注册时长、上次购买距今天数
- 两次事件之间的时间间隔

**周期性特征编码**：
- 使用正弦和余弦编码捕捉周期性
- hour_sin = sin(2π × hour / 24)
- hour_cos = cos(2π × hour / 24)
- 优点：23点和0点的距离很近，而不是很远

**滑动窗口特征**：
- 过去N天的平均值、最大值、最小值
- 移动平均、指数移动平均
- 常用于时间序列预测

#### 6.3 聚合特征

聚合特征将多个数据点的信息汇总：

**分组聚合**：
- 按某个维度分组后计算统计量
- 例如：每个用户的平均消费金额、每个商品的平均评分
- 常用统计量：均值、中位数、标准差、最大值、最小值、计数

**滑动聚合**：
- 在时间窗口内计算统计量
- 例如：过去7天的平均销售额
- 可以使用不同的窗口大小

**累计聚合**：
- 从起始到当前的累计统计量
- 例如：累计购买次数、累计消费金额
- 常用于时间序列数据

**交叉聚合**：
- 按多个维度分组聚合
- 例如：每个用户在每个商品类别的购买次数
- 可以捕捉更细粒度的模式

#### 6.4 领域特定特征

不同领域需要构建特定的特征：

**电商领域**：
- 用户行为特征：浏览次数、加购次数、购买次数、转化率
- RFM特征：最近购买时间(R)、购买频率(F)、购买金额(M)
- 用户偏好特征：最喜欢的品类、品牌、价格区间
- 时序特征：购买周期、活跃时段

**金融领域**：
- 技术指标：移动平均、RSI、MACD、布林带
- 风险指标：波动率、最大回撤、夏普比率
- 财务比率：市盈率、市净率、资产负债率
- 信用特征：信用历史长度、逾期次数、负债比率

**自然语言处理**：
- 文本统计特征：文本长度、句子数量、平均句长
- 词汇特征：词汇丰富度、罕见词比例
- 情感特征：情感极性、情感强度
- 主题特征：LDA主题分布

**计算机视觉**：
- 颜色特征：颜色直方图、颜色矩
- 纹理特征：LBP、GLCM、Gabor特征
- 形状特征：Hu矩、轮廓特征
- 深度特征：CNN提取的特征向量

## 常见问题

### Q1: 特征工程和特征选择有什么区别？

**特征工程**是从原始数据中构建新特征的过程，包括特征转换、特征组合、特征提取等。**特征选择**是从已有特征中筛选出最有价值的子集，目的是降低维度、减少过拟合、提高模型性能。特征工程通常在特征选择之前进行。

### Q2: 如何判断一个特征是否有价值？

可以通过以下方法判断：
1. **相关性分析**：计算特征与目标变量的相关系数
2. **可视化**：绘制特征与目标变量的关系图
3. **模型评估**：添加/移除特征后观察模型性能变化
4. **特征重要性**：使用树模型计算特征重要性
5. **领域知识**：结合业务理解判断特征是否有意义

### Q3: 高基数类别特征应该怎么处理？

高基数类别特征（如用户ID、城市名）的处理方法：
1. **目标编码**：用目标变量的统计值编码，需要防止过拟合
2. **频率编码**：用类别出现的频率编码
3. **哈希编码**：映射到固定维度的向量
4. **嵌入编码**：使用神经网络学习低维表示
5. **分组**：将低频类别合并为"其他"

### Q4: 特征缩放对哪些算法是必要的？

特征缩放对以下算法是必要的：
- **基于距离的算法**：KNN、SVM、K-Means
- **基于梯度下降的算法**：线性回归、逻辑回归、神经网络
- **正则化模型**：Lasso、Ridge、Elastic Net

对以下算法不必要：
- **树模型**：决策树、随机森林、GBDT、XGBoost
- **基于规则的模型**：朴素贝叶斯

### Q5: 如何避免特征工程中的数据泄露？

数据泄露是指在特征工程中使用了不应该知道的信息，导致模型评估过于乐观。避免方法：
1. **时间顺序**：对于时间序列数据，只使用过去的数据构建特征
2. **交叉验证**：在交叉验证的每一折内部进行特征工程
3. **目标编码**：使用留一法或K折交叉验证编码
4. **划分数据集**：先划分训练集和测试集，再进行特征工程
5. **Pipeline**：使用sklearn的Pipeline确保特征工程步骤在交叉验证内部执行

### Q6: 特征工程需要多少时间？

在实际项目中，特征工程通常占据60%-80%的时间。具体时间取决于：
- 数据质量和复杂度
- 业务问题的复杂程度
- 团队对领域的熟悉程度
- 可用的工具和资源

建议：
- 初期投入足够时间理解数据和业务
- 迭代式开发，逐步优化特征
- 记录特征工程的过程和决策
