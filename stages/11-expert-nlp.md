## 学习内容

### 1. NLP基础 (2-3周)

#### 1.1 文本预处理

文本预处理是NLP任务的基础，直接影响后续模型的性能。高质量的预处理能够显著提升模型效果。

**分词（Tokenization）**
分词是将连续文本切分为有意义的词汇单元的过程。中文分词尤其具有挑战性，因为中文没有明确的词边界。

主要分词方法：
- **基于规则的分词**：使用词典和规则进行分词，如最大匹配法、最小切分法
- **基于统计的分词**：利用统计模型如HMM、CRF进行分词
- **基于深度学习的分词**：使用BiLSTM、Transformer等模型进行分词

常用工具：
- jieba：Python中文分词库，支持精确模式、全模式和搜索引擎模式
- HanLP：多语言自然语言处理工具包
- Stanford NLP：斯坦福大学开发的NLP工具包
- spaCy：工业级NLP工具，支持多种语言

**词干提取（Stemming）**
词干提取是将词汇还原为词干或词根的过程，主要用于英文等屈折语言。

常见算法：
- Porter Stemmer：最经典的词干提取算法，基于规则
- Lancaster Stemmer：更激进的词干提取，可能过度提取
- Snowball Stemmer：支持多种语言的改进算法

**词形还原（Lemmatization）**
词形还原是将词汇还原为词典中的标准形式（词元），比词干提取更精确。

实现方法：
- 基于词典的方法：使用WordNet等词典资源
- 基于规则的方法：结合词性标注进行还原
- 基于深度学习的方法：使用预训练模型进行词形还原

**停用词（Stop Words）**
停用词是在文本中频繁出现但通常不携带重要语义信息的词汇，如"的"、"了"、"是"等。

处理策略：
- 使用标准停用词表（如哈工大停用词表、百度停用词表）
- 根据任务自定义停用词表
- 保留否定词和情感词

#### 1.2 文本表示

文本表示是将文本转换为计算机可处理的数值形式的过程。

**词袋模型（Bag of Words, BoW）**
词袋模型是最简单的文本表示方法，将文本表示为词汇的集合，忽略语法和词序。

特点：
- 简单直观，易于实现
- 忽略词序和上下文信息
- 高维稀疏表示
- 无法处理未登录词（OOV）

改进方法：
- 二元词袋（Binary BoW）
- 词频词袋（Count BoW）
- 归一化词袋（Normalized BoW）

**TF-IDF（Term Frequency-Inverse Document Frequency）**
TF-IDF是一种统计方法，用于评估词汇在文档集合中的重要性。

计算公式：
- TF（词频）= 词汇在文档中出现的次数 / 文档总词数
- IDF（逆文档频率）= log(文档总数 / 包含该词汇的文档数)
- TF-IDF = TF × IDF

特点：
- 考虑词汇在整个语料库中的分布
- 能够降低常见词的权重
- 广泛用于信息检索和文本挖掘
- 仍然无法捕捉语义信息

**N-gram模型**
N-gram模型考虑词汇的上下文信息，将连续的N个词汇作为一个单元。

类型：
- Unigram（1-gram）：单个词汇
- Bigram（2-gram）：连续两个词汇
- Trigram（3-gram）：连续三个词汇
- 4-gram及更高阶

应用：
- 语言模型：预测下一个词的概率
- 文本分类：提取局部特征
- 机器翻译：翻译模型

#### 1.3 词嵌入（Word Embeddings）

词嵌入是将词汇映射到低维稠密向量空间的技术，能够捕捉词汇的语义信息。

**Word2Vec**
Word2Vec是Google在2013年提出的词嵌入方法，包含两种训练架构：

CBOW（Continuous Bag of Words）：
- 根据上下文词汇预测中心词
- 训练速度快，适合大规模语料
- 对高频词效果更好

Skip-gram：
- 根据中心词预测上下文词汇
- 适合处理低频词
- 语义表示更准确

训练技巧：
- 负采样（Negative Sampling）：降低计算复杂度
- 层次softmax：加速训练过程
- 动态窗口：随机调整上下文窗口大小

**GloVe（Global Vectors for Word Representation）**
GloVe是斯坦福大学提出的词嵌入方法，结合了全局统计信息和局部上下文信息。

特点：
- 基于词共现矩阵
- 捕捉全局统计信息
- 训练效率高
- 支持多种向量维度

**FastText**
FastText是Facebook提出的词嵌入方法，通过子词（subword）信息处理未登录词。

优势：
- 能够处理未登录词
- 支持形态学丰富的语言
- 训练速度快
- 提供预训练词向量

**词嵌入评估**
- 类比任务：如"国王-男人+女人=女王"
- 相似度任务：计算词汇间的语义相似度
- 下游任务：在具体NLP任务上的表现

### 2. Transformer架构 (3-4周)

#### 2.1 注意力机制（Attention Mechanism）

注意力机制是Transformer的核心创新，使模型能够动态关注输入序列的不同部分。

**自注意力（Self-Attention）**
自注意力机制允许序列中的每个位置关注序列中的所有其他位置。

计算过程：
1. 将输入向量X通过三个线性变换得到Query(Q)、Key(K)、Value(V)
2. 计算注意力分数：Attention(Q,K,V) = softmax(QK^T/√d_k)V
3. 缩放因子√d_k防止点积过大导致softmax梯度消失

数学公式：
```
Attention(Q,K,V) = softmax(QK^T/√d_k)V
```

**多头注意力（Multi-Head Attention）**
多头注意力通过并行计算多个注意力头，捕捉不同子空间的信息。

实现步骤：
1. 将Q、K、V分别线性变换为h个头
2. 对每个头独立计算自注意力
3. 拼接所有头的输出
4. 通过线性变换得到最终输出

优势：
- 捕捉不同层次的语义信息
- 提高模型的表达能力
- 增强模型的泛化能力

**位置编码（Positional Encoding）**
由于Transformer没有循环结构，需要通过位置编码注入位置信息。

常用方法：
- 正弦余弦位置编码：使用不同频率的正弦和余弦函数
- 可学习位置编码：将位置编码作为可训练参数
- 相对位置编码：编码相对位置而非绝对位置
- 旋转位置编码（RoPE）：用于大语言模型

#### 2.2 Transformer结构

**编码器（Encoder）**
编码器负责将输入序列编码为上下文相关的表示。

结构组成：
1. 多头自注意力层
2. 前馈神经网络层
3. 残差连接
4. 层归一化（Layer Normalization）

特点：
- 双向注意力，捕捉全局上下文
- 适合理解类任务
- 并行计算效率高

**解码器（Decoder）**
解码器负责基于编码器的输出生成目标序列。

结构组成：
1. 掩码多头自注意力层（防止看到未来信息）
2. 编码器-解码器注意力层
3. 前馈神经网络层
4. 残差连接和层归一化

特点：
- 自回归生成，逐步生成序列
- 适合生成类任务
- 掩码确保生成顺序性

**前馈网络（Feed-Forward Network）**
前馈网络对每个位置独立应用相同的非线性变换。

结构：
- 两个线性变换
- 中间使用ReLU或GELU激活函数
- 通常中间维度是输入维度的4倍

**残差连接（Residual Connection）**
残差连接通过跳跃连接缓解深层网络的梯度消失问题。

作用：
- 缓解梯度消失问题
- 加速模型收敛
- 允许训练更深的网络

#### 2.3 Transformer变体

**GPT系列（解码器架构）**
GPT采用Transformer的解码器架构，专注于文本生成任务。

特点：
- 自回归语言模型
- 单向注意力（只能看到左侧上下文）
- 适合文本生成、对话系统
- 通过提示工程（Prompt Engineering）适应多种任务

**BERT（编码器架构）**
BERT采用Transformer的编码器架构，专注于文本理解任务。

特点：
- 双向注意力
- 掩码语言模型（MLM）
- 下一句预测（NSP）
- 适合分类、问答、NER等理解任务

**T5（编码器-解码器架构）**
T5采用完整的Transformer架构，将所有NLP任务统一为文本到文本的格式。

特点：
- 统一的任务框架
- 多任务学习
- 强大的迁移学习能力
- 支持多种生成任务

### 3. 预训练语言模型 (3-4周)

#### 3.1 BERT

**掩码语言模型（Masked Language Model, MLM）**
MLM是BERT的预训练任务之一，通过随机掩码输入词汇来训练模型。

训练过程：
1. 随机选择15%的词汇进行掩码
2. 80%替换为[MASK]标记
3. 10%替换为随机词汇
4. 10%保持不变
5. 模型预测被掩码的原始词汇

优势：
- 捕捉双向上下文信息
- 预训练任务简单有效
- 适合理解类任务

**下一句预测（Next Sentence Prediction, NSP）**
NSP是BERT的另一个预训练任务，判断两个句子是否连续。

训练过程：
1. 50%正样本：真实的连续句子对
2. 50%负样本：随机配对的句子
3. 模型预测是否为下一句关系

作用：
- 捕捉句子间关系
- 提升下游任务性能
- 增强模型的理解能力

**微调方法（Fine-tuning）**
微调是将预训练模型适配到具体任务的过程。

微调策略：
- 全量微调：更新所有参数
- 冻结底层：只微调顶层参数
- 分层学习率：不同层使用不同学习率
- 适配器（Adapter）：添加小型适配器模块

常用BERT变体：
- BERT-base：12层，768维，110M参数
- BERT-large：24层，1024维，340M参数
- 中文BERT：针对中文优化的版本

#### 3.2 GPT系列

**GPT-1/2/3/4**

GPT-1（2018）：
- 12层Transformer解码器
- 117M参数
- 引入无监督预训练+有监督微调范式

GPT-2（2019）：
- 48层Transformer解码器
- 1.5B参数
- 零样本学习能力
- 多任务学习

GPT-3（2020）：
- 96层Transformer解码器
- 175B参数
- 少样本学习能力
- 涌现能力（Emergent Abilities）

GPT-4（2023）：
- 多模态能力（文本+图像）
- 更强的推理能力
- 更好的安全性
- 更广泛的应用

**自回归生成（Autoregressive Generation）**
自回归生成是GPT系列的生成方式，逐步生成序列。

生成过程：
1. 输入起始提示（Prompt）
2. 模型预测下一个词的概率分布
3. 采样得到下一个词
4. 将新词加入输入序列
5. 重复步骤2-4直到生成结束标记

采样策略：
- 贪心搜索（Greedy Search）：选择概率最高的词
- 束搜索（Beam Search）：保留多个候选序列
- 随机采样（Random Sampling）：根据概率分布随机选择
- Top-k采样：只从概率最高的k个词中采样
- Top-p采样（Nucleus Sampling）：从累积概率超过p的词中采样

**指令微调（Instruction Tuning）**
指令微调是提升大语言模型遵循指令能力的技术。

方法：
- 收集指令数据集
- 使用指令格式重新组织数据
- 在指令数据上微调模型
- 使用强化学习从人类反馈中学习（RLHF）

数据格式：
```
用户：请将以下英文翻译成中文：Hello, how are you?
助手：你好，你好吗？
```

#### 3.3 其他预训练模型

**RoBERTa**
RoBERTa是BERT的优化版本，通过改进训练策略提升性能。

改进点：
- 移除NSP任务
- 动态掩码
- 更大批次大小
- 更多训练数据
- 更长训练时间

**ALBERT**
ALBERT是轻量化的BERT版本，通过参数共享减少模型大小。

优化技术：
- 词嵌入矩阵分解
- 跨层参数共享
- 句子顺序预测（SOP）替代NSP

**XLNet**
XLNet结合了自回归和自编码的优点，通过排列语言模型提升性能。

特点：
- 排列语言模型
- 双向上下文
- 自回归生成
- 更好的长文本处理

**T5**
T5将所有NLP任务统一为文本到文本的格式。

框架：
- 输入：任务描述 + 输入文本
- 输出：目标文本
- 支持多种任务：分类、摘要、翻译、问答等

### 4. NLP应用 (3-4周)

#### 4.1 文本分类

**情感分析（Sentiment Analysis）**
情感分析是识别文本中表达的情感倾向的任务。

任务类型：
- 二分类：正面/负面
- 多分类：正面/中性/负面
- 细粒度情感分析：识别具体情感维度
- 方面级情感分析：识别特定方面的情感

应用领域：
- 产品评论分析
- 社交媒体监控
- 舆情分析
- 客户反馈分析

**主题分类（Topic Classification）**
主题分类是将文本分配到预定义主题类别的任务。

方法：
- 传统方法：TF-IDF + 机器学习（SVM、随机森林）
- 深度学习：CNN、RNN、Transformer
- 预训练模型：BERT、RoBERTa微调
- 主题模型：LDA、NMF

**垃圾邮件检测（Spam Detection）**
垃圾邮件检测是识别垃圾邮件或恶意内容的任务。

特征工程：
- 文本特征：词汇、短语、句式
- 元数据特征：发件人、时间、主题
- 链接特征：URL数量、域名信息
- 行为特征：发送频率、收件人数量

#### 4.2 序列标注

**命名实体识别（Named Entity Recognition, NER）**
NER是识别文本中具有特定意义的实体的任务。

实体类型：
- 人名（PER）
- 地名（LOC）
- 机构名（ORG）
- 时间（TIME）
- 数字（NUM）
- 专有名词

标注方案：
- BIO标注：B-实体开始，I-实体内部，O-非实体
- BIOES标注：B-开始，I-内部，O-非实体，E-结束，S-单字实体
- BMES标注：B-开始，M-中间，E-结束，S-单字

**词性标注（Part-of-Speech Tagging, POS）**
词性标注是为文本中的每个词汇标注其词性的任务。

词性类别：
- 名词（N）
- 动词（V）
- 形容词（A）
- 副词（AD）
- 介词（P）
- 连词（C）

**分词（Word Segmentation）**
中文分词是将连续的中文文本切分为词汇序列的任务。

挑战：
- 歧义切分：如"南京市长江大桥"
- 未登录词：新词、专业术语
- 分词标准不一致

#### 4.3 文本生成

**摘要生成（Summarization）**
摘要生成是自动生成文本摘要的任务。

类型：
- 抽取式摘要：从原文中选择重要句子
- 生成式摘要：生成新的摘要文本
- 混合式摘要：结合抽取和生成

方法：
- 传统方法：TextRank、LexRank
- 序列到序列：Encoder-Decoder模型
- 预训练模型：BART、T5、PEGASUS

**对话生成（Dialogue Generation）**
对话生成是生成自然对话响应的任务。

类型：
- 任务型对话：完成特定任务
- 开放域对话：自由聊天
- 问答对话：回答问题

模型：
- Seq2Seq模型
- 注意力机制模型
- 预训练对话模型（DialoGPT、Blender）

**故事生成（Story Generation）**
故事生成是自动生成连贯、有逻辑的故事的任务。

挑战：
- 长文本连贯性
- 情节逻辑性
- 角色一致性
- 创意性

方法：
- 基于模板的方法
- 基于规划的方法
- 基于大语言模型的方法

#### 4.4 问答系统

**抽取式问答（Extractive QA）**
抽取式问答是从给定文本中抽取答案片段的任务。

任务格式：
- 输入：问题 + 上下文文本
- 输出：答案在上下文中的起始和结束位置

代表模型：
- BERT-QA
- ALBERT-QA
- RoBERTa-QA

**生成式问答（Generative QA）**
生成式问答是基于给定文本生成答案的任务。

特点：
- 答案不需要在原文中
- 可以进行推理和总结
- 更灵活的答案形式

模型：
- T5
- BART
- GPT系列

**开放域问答（Open-Domain QA）**
开放域问答是从大规模知识库中检索和回答问题的任务。

系统架构：
- 检索器（Retriever）：从知识库中检索相关文档
- 阅读器（Reader）：从检索结果中提取答案
- 生成器（Generator）：生成最终答案

代表系统：
- DrQA
- RAG（Retrieval-Augmented Generation）
- REALM

### 5. 大语言模型(LLM)应用 (2-3周)

#### 5.1 提示工程（Prompt Engineering）

**零样本（Zero-shot）**
零样本学习是指在没有示例的情况下，仅通过任务描述让模型完成任务。

技巧：
- 清晰的任务描述
- 明确的输出格式
- 适当的约束条件
- 角色设定

示例：
```
请将以下英文翻译成中文：
"Hello, how are you?"
```

**少样本（Few-shot）**
少样本学习是通过提供少量示例来引导模型完成任务。

技巧：
- 选择有代表性的示例
- 示例格式保持一致
- 示例数量适中（通常3-5个）
- 示例覆盖边界情况

示例：
```
请将以下英文翻译成中文：
英文：Hello
中文：你好

英文：Thank you
中文：谢谢

英文：Good morning
中文：早上好

英文：How are you?
中文：
```

**思维链（Chain of Thought, CoT）**
思维链是引导模型展示推理过程的技术，能够提升复杂任务的性能。

类型：
- 零样本思维链：添加"让我们一步一步思考"
- 少样本思维链：提供带推理过程的示例
- 自洽性（Self-Consistency）：多次采样取多数结果

示例：
```
问题：小明有5个苹果，给了小红2个，又买了3个，现在有多少个？
推理过程：
1. 小明开始有5个苹果
2. 给了小红2个，剩下5-2=3个
3. 又买了3个，现在有3+3=6个
答案：6个
```

#### 5.2 RAG（检索增强生成）

**向量数据库（Vector Database）**
向量数据库是存储和检索向量化数据的专用数据库。

常用向量数据库：
- Milvus：开源向量数据库，支持大规模部署
- Pinecone：云原生向量数据库
- Weaviate：开源向量搜索引擎
- ChromaDB：轻量级向量数据库
- FAISS：Facebook开源的向量检索库

功能特点：
- 高效的向量检索
- 支持多种索引类型（IVF、HNSW等）
- 元数据过滤
- 实时更新

**文档检索（Document Retrieval）**
文档检索是从大规模文档集合中检索相关文档的过程。

检索方法：
- 稀疏检索：基于关键词匹配（BM25、TF-IDF）
- 稠密检索：基于语义相似度（向量检索）
- 混合检索：结合稀疏和稠密检索

检索流程：
1. 文档预处理和分块
2. 文档向量化（使用嵌入模型）
3. 建立索引
4. 查询向量化
5. 相似度检索
6. 结果排序和过滤

**上下文学习（In-Context Learning）**
上下文学习是将检索到的文档作为上下文提供给语言模型的方法。

实现方式：
- 文档拼接：将检索结果拼接到提示中
- 动态提示：根据检索结果动态生成提示
- 多轮检索：迭代检索和生成

优化策略：
- 文档分块策略（固定大小、语义分块）
- 检索数量优化
- 上下文窗口管理
- 结果去重和排序

#### 5.3 微调技术

**全量微调（Full Fine-tuning）**
全量微调是更新模型所有参数的微调方法。

特点：
- 效果通常最好
- 需要大量计算资源
- 容易过拟合小数据集
- 训练时间较长

适用场景：
- 大规模数据集
- 计算资源充足
- 追求最佳性能

**LoRA（Low-Rank Adaptation）**
LoRA通过低秩分解减少可训练参数数量。

原理：
- 冻结预训练模型参数
- 在注意力层添加低秩矩阵
- 只训练低秩矩阵参数
- 推理时将低秩矩阵合并到原参数

优势：
- 参数效率高（通常只训练1%的参数）
- 训练速度快
- 内存占用小
- 支持多任务适配

实现：
```python
from peft import LoraConfig, get_peft_model

config = LoraConfig(
    r=8,  # 低秩矩阵的秩
    lora_alpha=32,  # 缩放因子
    target_modules=["q_proj", "v_proj"],  # 目标模块
    lora_dropout=0.1,
    bias="none",
)

model = get_peft_model(base_model, config)
```

**QLoRA（Quantized LoRA）**
QLoRA结合了量化和LoRA技术，进一步减少内存占用。

技术特点：
- 4-bit量化基础模型
- 双重量化（Double Quantization）
- 分页优化器（Paged Optimizers）
- 使用LoRA进行微调

优势：
- 极低的内存占用
- 可以在消费级GPU上微调大模型
- 保持接近全量微调的性能

**PEFT（Parameter-Efficient Fine-Tuning）**
PEFT是一系列参数高效微调方法的统称。

主要方法：
- LoRA及其变体（LoRA、AdaLoRA、QLoRA）
- Prefix Tuning：在输入前添加可训练的前缀向量
- Prompt Tuning：学习软提示（soft prompts）
- Adapter Tuning：在Transformer层间添加适配器模块
- BitFit：只训练偏置参数

选择建议：
- 资源充足：全量微调
- 资源有限：LoRA或QLoRA
- 多任务场景：LoRA + 任务适配器
- 超大模型：QLoRA

## 常见问题

### Q1: 学习NLP需要什么基础？

**A**: 学习NLP需要以下基础：

1. **编程基础**：熟悉Python编程，了解基本的数据结构和算法
2. **数学基础**：
   - 线性代数：向量、矩阵运算
   - 概率统计：概率分布、贝叶斯定理
   - 微积分：梯度、导数
3. **机器学习基础**：了解常见的机器学习算法和概念
4. **深度学习基础**：熟悉神经网络、CNN、RNN等基本概念

建议先完成机器学习和深度学习的学习，再进入NLP领域。

### Q2: NLP和自然语言理解（NLU）、自然语言生成（NLG）有什么区别？

**A**: NLP、NLU和NLG的关系如下：

- **NLP（Natural Language Processing）**：自然语言处理，是一个广泛的领域，包含所有与自然语言相关的处理任务。
- **NLU（Natural Language Understanding）**：自然语言理解，是NLP的子领域，专注于让计算机理解人类语言的含义。包括文本分类、情感分析、命名实体识别等任务。
- **NLG（Natural Language Generation）**：自然语言生成，是NLP的另一个子领域，专注于让计算机生成人类可读的自然语言。包括文本摘要、对话生成、故事生成等任务。

简单来说，NLP = NLU + NLG。

### Q3: 如何选择合适的预训练模型？

**A**: 选择预训练模型需要考虑以下因素：

1. **任务类型**：
   - 理解类任务（分类、NER、问答）：选择BERT系列
   - 生成类任务（摘要、翻译、对话）：选择GPT、T5、BART
   - 多任务：选择T5等统一框架模型

2. **语言支持**：
   - 英文任务：BERT、GPT、RoBERTa
   - 中文任务：BERT-wwm、RoBERTa-wwm、ChatGLM、Qwen
   - 多语言任务：mBERT、XLM-RoBERTa

3. **计算资源**：
   - 资源充足：选择大模型（BERT-large、GPT-3）
   - 资源有限：选择小模型（BERT-base、DistilBERT）或使用LoRA等高效微调方法

4. **数据规模**：
   - 数据充足：全量微调
   - 数据有限：少样本学习或提示工程

### Q4: 如何处理NLP中的数据不足问题？

**A**: 处理数据不足的方法：

1. **数据增强**：
   - 同义词替换
   - 回译（Back Translation）
   - 文本混合（TextMix）
   - 生成对抗网络（GAN）

2. **迁移学习**：
   - 使用预训练模型
   - 领域自适应预训练
   - 多任务学习

3. **少样本学习**：
   - 提示工程（Prompt Engineering）
   - 元学习（Meta-Learning）
   - 对比学习（Contrastive Learning）

4. **半监督学习**：
   - 自训练（Self-Training）
   - 一致性正则化
   - 伪标签（Pseudo Labeling）

5. **数据标注**：
   - 主动学习（Active Learning）
   - 弱监督学习
   - 远程监督（Distant Supervision）

### Q5: 如何评估NLP模型的性能？

**A**: NLP模型的评估方法：

1. **分类任务**：
   - 准确率（Accuracy）
   - 精确率（Precision）
   - 召回率（Recall）
   - F1分数
   - AUC-ROC

2. **序列标注任务**：
   - 实体级别F1
   - 标签级别F1
   - 准确率

3. **生成任务**：
   - BLEU（机器翻译）
   - ROUGE（文本摘要）

### Q7: 学习NLP有哪些常见的坑？

**A**: 学习NLP的常见坑：

1. **过度依赖预训练模型**：
   - 不理解模型原理，只会调用API
   - 建议：深入理解模型架构和训练过程

2. **忽视数据质量**：
   - 数据预处理不充分
   - 噪声数据影响模型效果
   - 建议：重视数据清洗和预处理

3. **盲目追求SOTA**：
   - 只关注最新论文，忽视基础
   - 建议：打好基础，再追求前沿

4. **不重视评估**：
   - 只关注训练指标，忽视实际效果
   - 建议：建立完善的评估体系

5. **忽视工程实践**：
   - 只会训练模型，不会部署上线
   - 建议：学习模型部署和系统工程

6. **缺乏领域知识**：
   - 不了解具体应用场景的需求
   - 建议：深入理解业务场景
